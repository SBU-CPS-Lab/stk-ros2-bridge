# Python dependencies for the stk_bridge runtime, on top of whatever ROS 2
# Humble's Python environment already provides (rclpy, etc.).
#
# Install into the SAME Python environment ROS 2 Humble uses (Python 3.8 on
# the official Windows Humble build), so both `import rclpy` and
# `import agi.stk12` resolve in one interpreter. See
# docs/installation.md for the full environment setup, including
# why this must not be a separate venv from the one `local_setup.ps1`
# activates.
#
# agi.stk12 itself is NOT listed here: it ships as a wheel inside your STK
# 12.6 install (typically
# C:\Program Files\AGI\STK 12\bin\AgPythonAPI\agi.stk12-12.6.0-py3-none-any.whl)
# and must be pip-installed from that local path, not from PyPI:
#   pip install "C:\Program Files\AGI\STK 12\bin\AgPythonAPI\agi.stk12-12.6.0-py3-none-any.whl"
# scripts/check_environment.py verifies this install and its
# version at runtime.
